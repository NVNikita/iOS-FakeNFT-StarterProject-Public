# Декомпозиция эпиков (Profile Module)

Документ описывает поэтапную реализацию модуля “Профиль” и указывает, какие задачи входят в каждый этап. В коде используются учебные пометки “ЭПИК 1/2/3”, указывающие, к какому этапу относятся блоки. Основные шаги по эпикам также описаны в комментариях внутри ProfileViewController.swift.

## Эпик 1. Экран профиля
Ориентировочное время: 4–5 дней

Цель: Реализовать экран профиля с загрузкой данных и открытием сайта.
Ориентировочное время: 1–2 дней
Задачи:
1) UI экрана (ProfileView):
   - Аватар, имя, описание, сайт.
   - Счётчик лайков (на этом этапе допустим простой текст).
   - Кнопки “Мои NFT” и “Избранное” (действия подключатся на следующем этапе).
   - Кнопка “Редактировать” присутствует на экране (действие подключится на следующем этапе).

Ориентировочное время: 1 день
2) Загрузка профиля:
   - Использовать servicesAssembly.profileService.loadProfile.
   - По успеху — обновить UI методом profileView.updateUI(with:).

Ориентировочное время: 1 день
3) Открытие сайта:
   - По тапу на ссылку — открыть WKWebView (см. didTapOnWebsiteLabel в ProfileViewController).

Ориентировочное время: 1 день
4) Обработка ошибок:
   - UIAlertController с Retry и Cancel при ошибке загрузки.

Критерии готовности:
- Профиль загружается и корректно отображается.
- Ссылка открывается во встроенном браузере.
- Ошибки загрузки корректно обрабатываются.

## Эпик 2. Экран редактирования
Ориентировочное время: 4–6 дней

Цель: Обеспечить редактирование профиля и сохранение изменений.

Задачи:
- Создать экран редактирования (контроллер, вью, слой презентации/интерактора/роутера — по выбранной архитектуре).
- Отобразить текущие данные (имя, описание, сайт, аватар).
- При сохранении — собрать значения полей и отправить обновления профиля.
- Валидация:
  - URL аватара — базовая проверка (http/https).
  - Остальные поля — базовая (пустые строки допускаются по умолчанию).
- По успеху — закрыть экран, передать обновленный профиль вызывающей стороне и обновить UI.

Критерии готовности:
- Экран редактирования открывается и закрывается.
- Изменения корректно сохраняются и отображаются на экране профиля.

## Эпик 3. Экраны “Мои NFT” и “Избранное”
Ориентировочное время: 5–7 дней

Цель: Отобразить списки NFT (свои и избранные), реализовать лайки и их синхронизацию с сервером.

Ориентировочное время: 2 день
Задачи:
1) “Мои NFT”:
   - Получить массив идентификаторов NFT из профиля.
   - Загрузить NFT по идентификаторам через сервис myNftService.
   - Открыть экран со списком и отобразить данные.
   - Реализовать сортировку (цена/рейтинг/имя), хранить выбор в UserDefaults.

Ориентировочное время: 2 день
2) “Избранное”:
   - Использовать локальное хранилище лайков (например, LikesStorage).
   - Загрузить NFT по идентификаторам из лайков и открыть экран избранного.

Ориентировочное время: 2 день
3) Лайки:
   - На экранах NFT по тапу на лайк — обновлять локальное хранилище лайков.
   - При уходе со страницы — инициировать обновление лайков на сервере из ProfileViewController.

Ориентировочное время: 1 день
4) UX загрузки:
   - При массовой загрузке NFT — блокировать взаимодействие и показывать индикатор.

Критерии готовности:
- Оба экрана открываются из профиля.
- Списки загружаются и отображаются.
- Лайки переключаются, сохраняются локально и синхронизируются с сервером при выходе со страниц.
- Сортировка применяется и сохраняется между запусками.

## Зависимости и подготовка

Необходимые сущности и сервисы (добавляются в проект по мере необходимости):
- ServicesAssembly с profileService и myNftService.
- Модель Profile и ProfileView.
- Локальное хранилище лайков (например, LikesStorage).
- Модель MyNFT и сервис для загрузки NFT по id.
- Экраны списков: “Мои NFT” и “Избранное” (контроллеры и их вью).

## Порядок выполнения

1) Эпик 1:
   - Реализовать UI и загрузку профиля.
   - Проверить открытие сайта и обработку ошибок.

2) Эпик 2:
   - Подключить экран редактирования, валидацию, сохранение и обновление UI.

3) Эпик 3:
   - Подключить экраны “Мои NFT” и “Избранное”, загрузку данных, лайки, сортировку и синхронизацию.

## Готово/Проверка

- Эпик 1: Профиль отображается, сайт открывается, ошибки обрабатываются.
- Эпик 2: Редактирование работает, изменения сохраняются и отображаются.
- Эпик 3: Списки работают, лайки синхронизируются, сортировка сохраняется и применяется.
