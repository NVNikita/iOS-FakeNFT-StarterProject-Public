# Эпик: Экран статистики

## Цель
Сделать экран с рейтингом пользователей, где можно посмотреть топ по NFT и перейти в профиль любого юзера.

## Архитектура и верстка
- **Архитектура**: MVC 
- **Верстка**: Программно (без сторибордов)
- **Сеть**: URLSession + GCD для фоновой загрузки

## Основной функционал
- Таблица с пользователями и их рейтингом
- Сортировка по рейтингу, имени или количеству NFT
- Переход в профиль пользователя по тапу на ячейку
- Обработка загрузки и ошибок
